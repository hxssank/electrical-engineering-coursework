# CEN 100 | Introduction to Engineering

Engineering practice connects a problem statement to requirements, design choices, and a way to check the result. The course introduces engineering disciplines, professional responsibilities, public and worker safety, and case studies.

## A requirement that can be checked

Consider a hypothetical sensor logger. "Record data reliably" leaves the reviewer guessing. "Record 10 voltage samples per second for 60 seconds, with a timestamp for every sample" defines an observable result.

The expected count is 600 samples. A verification plan would compare the count, timestamp spacing, and known input against the saved output. A count of 600 alone does not prove that the timing or measurements are correct.

This separates the requirement, the proposed design, and the evidence needed to accept it.
