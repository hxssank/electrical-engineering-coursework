# ECN 801 | Principles of Engineering Economics

Engineering economics compares project cash flows at a common point in time. The course covers cash-flow equivalence and measures of project worth, using discounted cash-flow methods under specified assumptions.

## Present-worth example

Suppose a hypothetical project costs $1,000 now and returns $600 at the end of each of the next two years. At a 10% annual discount rate:

```text
NPV = -1000 + 600 / 1.10 + 600 / 1.10²
    = $41.32
```

A positive result follows from those assumed cash flows and that discount rate. It is not proof that the project is low risk. A comparison should also examine changed operating costs, delayed returns, and alternatives. This example excludes taxes and assumes the stated cash flows occur.
