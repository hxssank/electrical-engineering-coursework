# MTH 110 | Discrete Mathematics I

Discrete mathematics provides methods for making precise claims about logical statements, sets, relations, and functions. This course emphasizes proofs and the difference between examples and general arguments.

## A short proof

To prove that the sum of two even integers is even, write the integers as `a = 2m` and `b = 2n`, where `m` and `n` are integers. Then:

```text
a + b = 2m + 2n = 2(m + n)
```

Because `m + n` is an integer, the sum is divisible by two. Checking a few pairs of even numbers would illustrate the statement, but would not prove it for every pair.

The same distinction matters when a software test passes selected inputs but a correctness argument must cover all permitted inputs.
