# MTH 140 | Calculus I

Calculus I studies limits, derivatives, extrema, and integration, including applications to changing quantities, areas, and volumes. Derivatives describe an instantaneous rate; integrals accumulate that rate over an interval.

## Charge and current

For an illustrative charge model `q(t) = 3t²` millicoulombs, with time in seconds:

```text
i(t) = dq/dt = 6t milliamperes
```

At two seconds the current is 12 mA. Integrating the current from zero to two seconds gives 12 mC, the same change obtained by subtracting the endpoint charges.

Tracking units makes the relationship easier to check: a millicoulomb per second is a milliampere. The mathematical model defines this example; it is not a measurement of an actual circuit.
