# MTH 141 | Linear Algebra

Linear algebra describes vectors, matrices, linear equations, transformations, and eigenvalues. These tools support circuit equations, coordinate changes, and numerical models with many interacting variables.

## Solving a coupled system

Consider the illustrative equations:

```text
2x + y = 5
 x - y = 1
```

Adding the equations gives `3x = 6`, so `x = 2` and `y = 1`. Substitution into both original equations checks the result. The coefficient matrix has determinant `-3`, so this system has one solution.

For larger systems, elimination performs the same operations systematically. In numerical work, a small residual checks how well a proposed answer satisfies the equations, while conditioning describes how sensitive the answer is to changes in the input.
