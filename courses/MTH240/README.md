## A local approximation

The exponential function has the power-series expansion:

```text
exp(x) = 1 + x + x²/2! + x³/3! + ...
```

Keeping terms through `x²` gives `exp(0.1) ≈ 1.105`. The next term is approximately `0.0001667`, which indicates the scale of the first omitted contribution. It is not, by itself, a general error bound for an arbitrary series.

An approximation needs both a region where it applies and a stated error criterion. Adding terms improves this example, but convergence must be checked before using a series as a numerical method.
