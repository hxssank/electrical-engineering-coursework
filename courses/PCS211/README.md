# PCS 211 | Physics: Mechanics

Mechanics uses forces, motion, and conservation laws to describe physical systems. Course topics include free-body diagrams, equilibrium, moments, friction, work, energy, and momentum.

## Moment of a force

A hypothetical 10 N force acting perpendicular to a 0.20 m lever arm produces:

```text
torque = force × perpendicular distance
       = 10 × 0.20
       = 2.0 N·m
```

If the force instead makes a 30° angle with the lever arm, the moment magnitude is `10 × 0.20 × sin(30°) = 1.0 N·m`.

A free-body diagram should state the reference point and include every external force. Equilibrium requires both zero net force and zero net moment; satisfying only one condition is insufficient.
